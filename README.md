## 第一筆生意

1. 準備月 0 有木頭、鐵各 3 個。開始木杖和鐵劍，各扣 1；仍在製作中。
2. 開店進入第 1 月，兩把完工。聽阿岑需求、逐件推薦，他自己持有兩件。
3. 他還在櫃臺時開材料委託，探索未知材料（6 枚），或先採購木頭／鐵。一人只能有一件未完成委託；交代後送客。
4. 關店不換月，櫃臺留開店按鈕，工坊仍能開始製作。再次開店收材料與鳥信；探索帶回銅 2 個。小禾提出新用途，多問一句學護腕配方與鑑定。
5. 沒合用現貨可接她的製作委託，條件足夠便開工。下月完工後等本人到櫃臺交貨，交貨才付款；客人處理完再下一位。

只按開店換月：生活費 8 枚、交付、製作完工、人物使用與鳥信一起更新。簡單裝備 1 個月，護符／金鈴 2 個月。沒有工時、製作容量、每日限額或現實倒數；材料足夠必成。製作經驗在完工時增加，品質與特性在開工時固定。

提早開關店不丟失需求。欠款不結束遊戲，銷售所得先還款。採購任意可安全計算的正整數，委託時記帳，下月交付一次。採購、探索、客人請工坊製作共用每人一件；各次操作檢查當前櫃臺與畫面版本。

## 裝備、故事與委託

新遊戲只認識木頭和鐵；探索逐步辨識銅、銀、金，各次帶回 2 個，未知材料不能先採購或製作。配方仍由對話／製作逐步揭露。六配方為木杖、鐵劍、木盾、銅護腕、銀護符、金鈴；普通售價按品質為 14／20／26。金鈴一次信任委託加 12，交貨才給。

客人委託成品會專門保留，不能一般出售，未領貨不算持有與使用。拒絕這次領貨，下月仍會再來。缺材料／品質的未開工委託可當面取消，再安排採購。已開工保證完成。

三位熟客各有三個原創內容節點，綁定真實裝備使用、持有期、結果與磨耗。新用途先於日常替換，避免較長工期讓故事一直輪不到。人物信任與故事需要真實使用證據。輕巧增加效能、堅固減少磨耗、護身改善防護結果；鑑定顯示細節。

磨損物由原持有者退役並當面贈還，實物回工坊後可免費修復一次、推薦給其他合用人物，或熔鍊成原材料與一次特性傳承。原退役者不買回同一件，熔鍊永久消耗實物。收藏簿保存來源、轉手、使用與傳承歷史。
