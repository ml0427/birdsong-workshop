原創正體中文文字工坊遊戲。你是溪岸工坊的學徒，製作裝備、聽熟客需求，再從魔法鳥的信裡了解裝備的後續。沒有玩家戰鬥，製作必定成功，沒有倒數或每日限額。

## 本機啟動

雙擊 `START.cmd`，或在專案資料夾執行：

```powershell
node server.cjs --open
```

啟動入口是 `http://127.0.0.1:4317`。保留伺服器視窗；按 Ctrl+C 停止。只綁定 127.0.0.1，無須安裝套件。需要 Node.js 22 以上，本機環境為 v24.11.0。Linux 請省略 `--open`。

本輪依使用者要求保持本機服務關閉。上方是使用者自行啟動的方式，不表示本輪重新啟動過服務。直接開 `index.html` 也可遊玩，但建議固定網址，避免 file 存檔行為差異。

## 第一筆生意

1. 木頭 1 做木杖，鐵 1 做鐵劍；仍是準備月 0。
2. 開店進入第 1 月，聽阿岑需求，逐件推薦。他會自己持有兩件武器。
3. 阿岑買完仍在櫃臺，先委託銅 1，再按「辦完了，送客」。還可向在場的他委託其他材料。
4. 關店，再開店。材料和鳥信一起到，小禾提出銅護腕防護需求。
5. 多問一句學新配方與鑑定；製作、鑑定、推薦。成交後顧客仍可接採購，送客才換下一位。

提早關店不結算、不清除未完成需求。開場兩件已售但尚未採購，阿岑會下次繼續等清單。生活費與採購款不足可欠款，所得先償還，不會結束遊戲。關店完全隱藏櫃臺，工作臺仍可製作。

## 裝備與舊物

六種裝備：木杖、鐵劍、木盾、銅護腕、銀護符、佩戴式魔法警示金鈴。普通價只按品質：樸實 14、細緻 20、精良 26 枚；金鈴的一次信任委託另有 12 枚獎勵，日常金鈴需求仍按普通價。

需求對話逐步揭露配方。鑑定顯示品質、材料階級、效能與耐久；推薦選單能分辨特性、耐久、傳承來源。輕巧提高效能，堅固減少使用磨耗，護身改善防護結果。效能影響 NPC 的實際使用信；每件每月最多使用一次，不會因讀檔或關店重複磨耗。

耐久低時，原持有者提出退役贈還。鳥信只是通知，要等本人到櫃臺才能當面領回。低耐久舊物不能推薦；每件可免費練習修復一次，再售給有合用需求的新持有者，或熔鍊成原材料與特性傳承。傳承一次移入同材質新作，最多兩個特性，精良品質也有差異。收藏簿保留每件的來源、歷任持有者、使用、贈還與熔鍊紀錄。

只有目前櫃臺人物能接新採購、交易、對話或贈還。採購接受任意可安全計算的正整數，沒有 9 個上限；非整數、非法材料或數值溢位會拒絕，款項與材料均不改動。顧客離開後，已接受的採購照常下月交付。

## 保存與遷移

操作後自動保存，支援上一筆備份復原、匯出 JSON、驗證後匯入及重新開始確認。從「保存」匯出備份。固定使用同一瀏覽器與網址；清除瀏覽器資料會影響進度。

schema 2 保持原 localStorage key，支援 schema 1 備份：舊木凳、澆水壺、銀燈會轉成木盾、銅護腕、銀護符，保留月份、金額、物品 ID、持有與交易歷史。舊版無使用證據的固定故事改為關係紀錄，真實使用歷史仍保留；新耐久從更新起計。已約定的贈還繼續有效。

Pages 無法直接讀 localhost 的資料。搬進度請先在原網址匯出，再到新網址匯入。兩個視窗更新時同步，舊畫面操作會被拒絕。

## 驗證與雲端復測

```sh
node --test tests/engine.test.cjs tests/view.test.cjs
node scripts/build.cjs
```

v0.5 已通過 42 項非瀏覽器測試（33 引擎、9 介面狀態／事件測試）及建置。詳見 `TEST_RESULTS.md`。這些測試不代表 CSS 尺寸或真正滑鼠操作已通過。

本輪沒有啟動本機瀏覽器。雲端可使用現有 Chromium 與隔離測試資料執行：

```sh
GAME_URL=https://ml0427.github.io/birdsong-workshop/ CHROME_PATH=/absolute/path/to/chromium node tests/browser.cjs
```

指定 GAME_URL 就不啟動本機遊戲伺服器；不指定則測試工具暫開 4328。工具使用新瀏覽器 profile，QA 報告、截圖與測試備份放在忽略的 `qa` 目錄。已更新為新版裝備與櫃臺流程，僅通過語法檢查，尚未實跑 v0.5。
