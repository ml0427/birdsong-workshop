原創正體中文文字工坊遊戲：製作裝備、接待三位固定熟客、探索材料，再從魔法鳥的信裡讀到真實使用結果。玩家沒有戰鬥。

## 獨立測試

主畫面點「獨立測試」，或開 [測試頁](https://ml0427.github.io/birdsong-workshop/lab.html)。六項為鍛造、裝備整理、櫃臺交易、材料取得、客人成長與劇情、店舖營運；成長另選三位人物或小禾缺裝備情境。

測試資料只在記憶體中，完全不讀寫正式存檔及備份。切換保留本頁內各自進度；「重置目前情境」只重置此情境；「返回正式遊戲」恢復正式頁原存檔。重載或關閉測試頁會重置全部測試。

鍛造只顯示材料、配方、排程、成品及月份開關店；材料無限，仍要依正常一月／兩月工期完成。其餘情境預備20個已知材料與200枚（營運只有4枚），人物史及所有權來自正式公開操作。除了營運逐筆閱卡，各專頁自動以正式操作閱完不相關月結，不改結算與劇情條件。沒有直接完成或任意改能力的按鈕。

v0.17 鍛造改用含六配方的緊湊選擇器，排程與成品獨立捲動；裝備整理先見木杖與鐵劍兩件退役代表樣本，其餘庫存折疊保留，本次新作另外標示。導言標記「起始情境」，不把初始金額與來訪描述當成現在狀態；開店後立即選擇測試、換角色或重置均可操作，狀態操作仍有連點防護。

正式遊戲配方用量與工期仍為現行規則；完整鍛造改版與技能點仍屬設計討論。以下自由配料只在測試頁試作，不寫入正式遊戲。

### 自由配料試作（v0.18）

進入鍛造，切「自由配料試作」。投入五種材料數量，開始試作，再按正常開店等一／兩月揭曉。每種0–20、總量1–40，合法非零配料一定完成；比例決定用途、總量增加耐久與品質。同組合用途穩定，每件開工抽1或2個既有有效特性，之後不重抽。

配料簿初有三份成品未知的筆記。未發現組合不列，該組合完成後才顯示成品與重用配料。完工前排程、提示及可訪問名稱不提前揭曉。最近四件展示配料、品質、效能／使用判定、耐久／預估磨耗與特性，方便比對同配料隨機差異及不同投入；使用判定與磨耗由正式算法計算，不發生玩家戰鬥。

試作和固定配方可切換，資料只留鍛造測試記憶體；重置鍛造清空兩者，其他情境與正式存檔保留。精確試作規則見SPEC.md，這不是正式完整鍛造改版。

## 第一筆生意

1. 準備月 0 有木頭、鐵各 3 個。開始木杖和鐵劍，各扣 1；仍在製作中。
2. 開店進入第 1 月，先逐筆看真實收支，再逐件看完工報告，閱完才接客。聽阿岑需求、逐件推薦，他自己持有兩件。
3. 他還在櫃臺時開材料委託，探索未知材料（6 枚），或先採購木頭／鐵。一人只能有一件未完成委託；材料服務可選，成交後可直接送客，下次來訪仍能補學。
4. 關店不換月，櫃臺留開店按鈕，工坊仍能開始製作。再次開店接待正常新客及收鳥信；即使未派遣，人物、鳥信與新需求仍可查看。若先探索，下月帶回銅 2 個；辨識後再談護腕配方。
5. 沒合用現貨可接她的製作委託，條件足夠便開工。下月完工後等本人到櫃臺交貨，交貨才付款；客人處理完再下一位。

只按開店換月：生活費 8 枚、交付、製作完工、人物使用與鳥信一起更新。基本作品 1 個月，複雜作品 2 個月。沒有工時、製作容量、每日限額或現實倒數；材料足夠必成。製作經驗在完工時增加，品質與特性在開工時固定。

提早開關店不丟失需求。欠款不結束遊戲，銷售所得先還款。採購任意可安全計算的正整數，委託時記帳，下月交付一次。採購、探索、勘路採集與客人請工坊製作共用每人一件；各次操作檢查當前櫃臺與畫面版本。

## 人物成長與目前目標

人物從首次實際接待起出現在人物頁，只顯示已相識者。預設先看每人的姓名、等級／能力與目前目標；點摘要展開線索、經歷和裝備。共同成長規則只列一次，裝備展開後，懸停或點擊特性名稱查閱效果。三人都有等級、能力說明、真實經歷與目前目標：阿岑「行路」、小禾「辨路」、望舒「感知」。每種不同可靠經歷加1點能力，每2種提升1級，本版各有3種成長來源；對話、交易、同類重複或空過月不能刷級。

小禾保留近程路線與通路任務。驛道恢復後，阿岑以本人耐用木杖與盾試走；望舒以本人護符與鈴確認干擾和警示。需要已有使用經驗、能力與當前裝備，實際使用後才記完成。兩條新目標各自完成便能向本人交代既有驛道採集（6枚，次月已知材料3個）；不用三人全解才通路。裝備可正常製作或委託補足，望舒可並行準備兩件，也可用堅固傳承配合逐件委託。舊存檔只推導可信能力，不補發新完成紀錄。

## 裝備、故事與委託

基本特性在配方、完工報告、推薦、作品架、傳承預覽及人物持有裝備旁只顯示名稱；懸停或點擊名稱看效果，鍵盤 focus／Enter／Escape 可查閱與收起，不需要先鑑定。輕巧效能＋1；堅固每次使用磨耗－1、最低1且不超過剩耐久；護身限鐵劍／木盾／護腕／護符使用判定＋2，不改面板效能。特性不加售價，NPC 使用結果才受影響。

新遊戲只認識木頭和鐵；探索逐步辨識銅、銀、金，通路恢復前各次帶回 2 個，未知材料不能先採購或製作。配方仍由對話／製作逐步揭露。六配方為木杖、鐵劍、木盾、銅護腕、銀護符、金鈴；普通售價按品質為 14／20／26。金鈴一次信任委託加 12，交貨才給。

客人委託成品會專門保留，不能一般出售，未領貨不算持有與使用。拒絕這次領貨，下月仍會再來。缺材料／品質的未開工委託可當面取消，再安排採購。已開工保證完成。

三位熟客各有三個原創內容節點，綁定真實裝備使用、持有期、結果與磨耗。尚未使用的新用途優先，之後優先較久未供應的用途，避免重複替換讓後續作品一直輪不到。人物信任與故事需要真實使用證據。輕巧增加效能、堅固減少磨耗、護身改善防護結果；鑑定顯示細節。

磨損物由原持有者退役並當面贈還，實物回工坊後可免費修復一次、推薦給其他合用人物，或熔鍊成原材料與一次特性傳承。原退役者不買回同一件，熔鍊永久消耗實物。收藏簿保存來源、轉手、使用與傳承歷史。

## 小禾的近程路線

小禾在場且沒有未完成委託時，可在材料委託頁選「近程勘路」。原本交代她探索新材料的可靠紀錄也能銜接；這是可選支線，原銅銀金與新手循環不需等它完成。

她的等級、辨路能力只因不同的真實探索及裝備使用經歷成長。多聽她回報，人物頁只顯示已有線索與下一缺口；裝備不足時可用既有現貨推薦或客人製作委託補足。交貨當月不立刻冒險，每月最多推進一個新勘路節點。

個人線勘查舊路標後，另一月的真實行動可重通舊驛道。通路恢復會讓往後接受的新探索由 2 個材料增為 3 個；原委託份量不追補。也可請小禾「沿驛道採集所選材料」，6 枚、次月 3 個已辨識材料；所以已全知材料的舊檔仍能使用效果。普通品質售價不變。

舊存檔只沿用可靠經歷推導能力，讀檔不補發新任務或世界完成。沒有可靠近程紀錄時仍可勘路，不因沒有新事件而卡死。

## v0.11 櫃臺與月結

成交／領貨後再交代材料任務，該人物的材料委託入口和新委託表單收起，只留回報月份與送客；背景任務繼續到下月，不自動送客。等候數只計尚未輪到的客人。

換月先看實際收支，再逐件看本次完工裝備，按下一筆，閱完才接客。現金扣款與新增欠款分開；先前付的材料款不重扣，未交貨不先收款。重載可接續，連點不跳卡、重扣或重產。完工報告不是鑑定；鑑定是選用的永久詳細標示與經驗，不是交易門檻。

月結轉場會忽略同一段快速滑鼠／觸控連點，避免第二下跳報告或穿入未選擇的製作。停止連點後正常單擊即可繼續；沒有額外確認步驟。
